## description

eval runtime refcount wiring: Value::Closure needs to reclaim arena slots when no Value references it. Today every reduce_lambda leaks a slot until the Interpreter drops (closure.rs retain/release are #[allow(dead_code)]). Approach: make ClosureHandle not Copy; on Clone increment the arena's refcount, on Drop decrement. Because Value needs Clone and Drop access to the arena, route via the Interpreter's closure arena held behind a shared cell (Rc<RefCell> or interior arena access). Generalize to Stream (M4) / Lazy (M5) when those land. Refcount handles acyclic cases; cycles deferred to WI-058 GC evaluation. Cycle-safety is conditional, not universal: holds while M4 streams stay lazy+non-memoized and Native stream sources respect a no-self-ref invariant. SharedStream memoization (proposal 026 post-v1) or Native sources that cache back-refs would need cycle detection at the insert site, same shape as proposal 026 §v2 Modify-store cycle checks.
