## Description

Collection literal with a tail: `[]`, `[a, b]`, `[h | t]`, `[a, b | t]`. A NEW SYNTAX (user, 2026-10-21): it replaces today's collection literal of kernel-language §4.6 (`[…]` as the `List` literal in every position, never built as another collection and never read through `Iteration.split`), and §4.6 is rewritten for it when this ticket is taken up; until then the List-only literal and `cons(h, t)` destructuring stand. THE SYNTAX: `[]` the empty collection; `[a, b]` exactly these elements, in this order; `[h | t]` a first element `h` and the rest `t`, a collection of the same type; `[a, b | t]` the first elements `a`, `b`, then the rest `t`. Elements are separated by `,`; the tail follows `|`, at most one, last. It is written in a pattern (a `match` case, a rule head) to take a collection apart, and in a value position to build one. THE METHOD OF IMPLEMENTATION IS NOT KNOWN YET (user, 2026-10-21). One earlier candidate, kept as history and not decided (proposal 019's sketch, the WI-560 discussion): a pattern read through `Iteration.split` (`[h | t]` is `split(c) = some((h, t))`, `[]` is `split(c) = none()`), a value built through `PersistentCollection.empty` / `insert`, and at `List` its constructors `cons` / `nil` with no `split`; that discussion noted that a rule head is matched by unification, which takes apart constructors only, that running `split` in a `match` is effectful at split's row, and that `Set` provides no `Iteration`. TODAY: patterns are structural (variable, wildcard, literal, constructor, tuple; `Pattern` in node_occurrence.rs) and never call an operation; the parse-only `[h | t]` surface was removed by WI-560; lists are destructured with `cons(h, t)`. TO DECIDE when taken up, likely as its own proposal: the method; what the literal is at a position that declares another collection (today a type mismatch) and at one that declares none (today `List`); how it relates to `PersistentCollection.fromList` (docs/brainstorms/fillable-collection-landscape.md §4); which collections take a pattern with a tail. REFERENCES: kernel-language §4.6; proposal 019 (the original sketch, kept as design history); proposal 011 OQ3; docs/brainstorms/fillable-collection-landscape.md (option B, the literal read through `split`, withdrawn for today's literal).
