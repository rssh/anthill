CONTEXT: follow-up to WI-711 + proposal 052 (docs/proposals/052-rules-as-stream-valued-operations.md -- relations as first-class Relation[T] values that provide LogicalStream[T]). WI-711 added query_id_set + collect_id_set to anthill-todo/anthill/main.anthill, which query the workflow rules (dep_satisfied) the ONLY way available today: the low-level reflect API -- fresh_var[Term]("id") + make_fn("anthill.stage0.workflow.dep_satisfied", cons(id_var,nil())) (a STRING-named goal) + pattern_query + execute(kb(),...) + a hand-written Solution-stream walk (collect_id_set) that pulls the ?id binding by string key via extract_string_field. cmd_next's walk_solutions (querying claimable) is the SAME boilerplate.
