SCOPE: spec stdlib file + integration tests that exercise the spec on the post-WI-307 typer. Depends on v1a (WI-307) shipped, ideally v1b (WI-328) and handler discharge (WI-329) too for full coverage. Completes proposal 013's deferred effect-checking.
