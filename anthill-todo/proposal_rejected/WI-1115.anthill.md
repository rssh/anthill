## description

anthill-todo backend, INCREMENT 3 of WI-437: MIRROR CARRIER + FAKE. Design: backend-github-coordination.md §8.3 and §6.1's contract, with proposal docs/proposals/054-external-effect.md; §14 row 3. Ships nothing on its own -- it ships something TESTABLE, which is the point. THE MIRROR IS A CARRIER SORT, NOT A NEW EFFECT: authority is possession (the bundle cannot touch the registry without holding the carrier), and the increment-1 factory decides which implementation a run holds. Its ops ride the GENERIC External effect (WI-699, delivered) -- one generic outside-world effect rather than one per capability, so the row vocabulary stays stable as backends multiply; the which-capability distinction is authority and lives in the carrier. Rows: mutators {Modify[m], External, Error}, reads {External, Error}, each the UNION over implementations (054 §Faking) -- the real carrier refines away Modify[m], the fake refines away External, which is what lets tests drive Branch searches over the fake while spec-typed production code stays out of Branch regions (Branch x External is rejected). Operations: create_issue, recent_issues (newest page, list endpoint, open+closed), issues_titled (exact-title search -- the §6.1 old-claimant leg), retitle, set_body, close/reopen, issue_comments/close_info (since-cursor comment listing plus close state and actor, for §7.3-§7.4), add_to_project. TWO IMPLEMENTATIONS, both first-class: one shelling out to `gh` (inheriting the user's existing auth -- no token handling of our own), and a FAKE over an in-memory issue list. The fake is not a test trick: it is the second implementation of a first-class seam, and it is what makes §6's race protocol testable without a network -- it can force the lost-race interleavings deterministically, and because its rows drop External a test may go further and search whole schedule spaces under Branch (027.2 solvers: `oracle` replays one interleaving, `all` enumerates and checks NO DUPLICATE IDS across every branch). Also here: ambient `fresh_token()` with row {External, Error} -- provisional entropy is NOT a mirror concern, it must be available with or without any mirror because §6.4 mints offline. Keep §8.3's forge-substitution contract honest: everything above the carrier consumes only its contract, so GitLab/Gitea/a plain coordination service is a new implementation plus a config variant, with zero change to the bundle.
