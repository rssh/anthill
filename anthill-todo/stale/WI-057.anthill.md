## description

Value::Entity.named field: change Vec<(Symbol, Value)> to SmallVec<[(Symbol, Value); 2]>. cons cells have exactly 2 named args (head, tail); entity constructors typically fit in 2-4. Saves a heap alloc per Entity value — significant on list-heavy workloads. Cross-cutting: eval.rs build_list_value + reduce_constructor + pattern.rs unify_constructor all allocate Vec today. Same rationale applies to Value::Tuple.named and Value::Entity.pos. Benchmark-driven; WI-053 companion.
