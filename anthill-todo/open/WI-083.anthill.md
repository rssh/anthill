## Description

Byte / byte-array support in anthill. Currently no first-class bytes sort — String is used as a stand-in for binary payloads (e.g. lf1's webots.Emitter.send / Receiver.get_data, which on the C++ side take/return const void* with explicit size). String stand-ins break for payloads containing null bytes and require reinterpret_cast to round-trip serialized structs. Needed: a Bytes sort (or List[T = Byte] equivalent) with primitive operations (length, concat, slice, from_string, to_string), Implementation facts mapping to std::string (size-tracked) or std::vector<std::byte> in C++, and parser/typing support for byte-literal syntax. Driven by lf1 webots bindings; will also be needed by blefusku (proto wire format).
