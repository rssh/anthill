## Description

WI-956 item 4 fixed the gates it named and PROVED the class is live. The rest of typing.rs still asks `kind_of`, and this ticket carries the proof so the next reader does not re-derive it.

THE DATUM, measured over stdlib + anthill-stl (2598 distinct symbols):
  - 68 symbols carry more than one category. 64 are [Entity, Sort] (the top-level `entity X(...)` sugar of §6.3), 4 are [Sort, Entity].
  - So for 64 sorts, `kind_of(s) == Some(Sort)` is FALSE while `has_kind(s, Sort)` is TRUE.
  - A name can also be [Entity, Sort, Operation] (`entity foo(k)` beside `operation foo(...)`), so the Operation direction diverges too.
  - `kind_of`'s own doc (kb/mod.rs) already says it is for DISPLAY and that `has_kind` is the membership question.

DRIVEN, not argued (wi956_kind_gate_tests, typing.rs):
    entity Rec(n: Int64)
    sort Rec
      sort T = ?
      operation peek(x: T) -> T
    end
  loads clean, and under `kind_of` `call_bracket_scopes(Rec.peek)` returned [] — the sort's own T missing from the bracket scopes. `has_kind` returns ["T"]. The same misread emptied the WI-565 bare-member hint.

WHAT WI-956 FIXED (do not redo): the five `impl_parent_of_op` + kind gates, now one `impl_parent_sort_of_op`; `member_owning_sorts_for_bare`; `genuine_concrete_sort` (the shared filled_carrier_sort / ground_rigid_projection_if_concrete test); ground_rigid's Operation gate.

WHAT IS LEFT — every remaining `kind_of(..) == Some(SymbolKind::..)` in typing.rs used as a TEST rather than for display. At the time of writing: ~4547, 6420, 7291, 8166, 9828, 10830, 14402(recheck), 18954, 18992, 22111, 26196, 26218, 27722, 28196, 29625. Grep rather than trust the line numbers.

DECIDE PER SITE, do not sweep blindly. Some may genuinely mean "was it WRITTEN with this keyword" (a diagnostic that echoes the source, reflect's `kind` string). Those must stay `kind_of` and say so at the site. The rest are membership questions and should switch.

ACCEPTANCE: each site either switched or annotated with why it is a display question; cargo-test green; name which tests fail when the change is backed out (WI-956's experience: for most of these, NOTHING fails without a purpose-built fixture — say so rather than implying a test justifies it).
