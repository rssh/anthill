## Description

A VALUE TYPED AT A SPEC IS TAKEN FOR A VALUE OF THE SPEC'S CARRIER — a reading no rule states, and the one that lets a requirement be met with no dictionary built. `sort Tag { sort T = ?; operation tagOf(x: T) -> Int64 }`, `sort Tagger { sort C = ?; requires Tag[T = C]; operation probe(x: C) -> Int64; operation tagIn(x: C) -> Int64 = Tag.tagOf(x) }`, `sort B { entity b(k: Int64); provides Tag[T = B]; operation tagOf(x: B) -> Int64 = 2; provides Tagger[C = B]; operation probe(x: B) -> Int64 = 7 }`, `sort Box { sort T = ?; requires Tag[T = T]; operation tagOf(v: T) -> Int64 = Tag.tagOf(v) }`, each entered with `b(k: 0)`. (1) `operation viaBodyless(w: Tagger) -> Int64 = Tagger.probe(w)` answers 7. (2) `viaDefaulted(w: Tagger) = Tagger.tagIn(w)` LOADS and dies "DeferToRequirement: requirement param `__req_tag` not bound in caller frame (running `Tagger.tagIn` ...; frame binds [])". (3) `viaOtherSort(w: Tagger) = Box.tagOf(w)` loads and dies the same way in `Box.tagOf`. (4) `projDefaulted(w: Tagger) -> Int64 requires Tag[T = w.C] = Tagger.tagIn(w)` loads and dies the same way. THE BOUND SPELLINGS RUN: `memberDefaulted(w: Tagger.C) = Tagger.tagIn(w)` and `memberOtherSort(w: Tagger.C) = Box.tagOf(w)` (section 5.4's sugar), and `boundDefaulted[P](w: P) requires Tagger[C = P] = Tagger.tagIn(w)` and `boundOtherSort[P](w: P) requires Tagger[C = P] = Box.tagOf(w)`, each answer 2. MEASURED 2026-10-05 on WI-20261005-2KV4Y's tree. THE RULE (user, 2026-10-05, stated as a more exact formulation that excludes a wrong reading, not as a proposal): providing `F[X]` lets the operations of `F` be used on a value of `X`; it does not substitute `F` for `X`. A value whose sort provides a spec is usable where a value of a sort that REQUIRES the spec is expected — a type parameter under `requires F[X = P]`, or `F.X` in a signature — and `w: Tagger` is not `w: Tagger.C`. A sort that receives on itself is not this case: `Stream` is its own carrier (`Stream provides Iterable[C = Self, ...]`), a `List` is a `Stream`, and `s: Stream` stays what it is. WHERE THE READING LIVES.
