## Description

Typing-pass parity test: verify the operations-form spec in docs/proposals/typing_pass_spec.anthill produces the same TypeOf facts as the Rust implementation in rustland/anthill-core/src/kb/typing.rs for a corpus of test programs. Approach: (a) build a small corpus of well-typed and ill-typed test programs covering: literals, variables, lambdas (with and without annotations), let, match (exhaustive and non-exhaustive), constructor patterns, operation calls, effect-row inference, type-parameter binding, structural unification of parameterized/arrow/named_tuple types, subtyping relationships. (b) run each program through the Rust typer; collect resulting TypeOf facts (per occurrence) and any LoadError diagnostics. (c) (when typing_pass_spec.anthill operations are wired as runnable anthill code) run the same programs through the spec; collect TypeOf facts; compare. Initial milestone before the spec is runnable: lock down a snapshot of expected TypeOf facts from the Rust typer as the reference, so the spec implementation has a concrete target to match. Reason WI-011 was closed in favor of this WI: the operations-form spec already exists; what's missing is the equivalence guarantee. Closes the practical concern WI-011 was capturing without the Horn-rules infrastructure ambition.
