String interpolation. Replace nested concat-chains with `s"...${expr}..."` form. Today bundle code constructs every output line via `concat("prefix ", concat(to_string(n), concat(" — ", desc)))` etc. — readable once you squint, ugly to write, easy to misorder. Add a string-template literal: `s"prefix ${n} — ${desc}"` desugars to a sequence of concat calls with `to_string` (or any other declared `Show` operation) applied to each interpolated expression's runtime type. The typer tracks which interpolated expressions need a coercion through `to_string`. Acceptance: every concat-chain in cmd_status / cmd_show / cmd_list / cmd_graph / cmd_next / cmd_feedback / cmd_add / cmd_claim / cmd_deliver / cmd_verify / cmd_delete output collapses to a single `s"..."` literal; cargo test green.
