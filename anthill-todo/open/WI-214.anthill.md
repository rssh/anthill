## Description

scaland mirror of WI-096 — proof cache for `anthill-smt-gen` (Z3 verdicts keyed by sha256 over emission bytes + transitive dep hashes). Mirrors `rustland/anthill-smt-gen/src/cache/{key,store,location,mod}.rs`. Cache key: sha256 over `emitted_smt_lib + tactic_canon + ordered_hint_qns + transitive_rule_dep_hash + transitive_fact_dep_hash + stdlib_version + z3_version + cache_format_version`. Layout: JSON-per-entry with two-level hex fanout under per-solver subtree `<root>/projects/<repo-hash>/proofs/z3/v1/`; XDG resolver with override chain `--cache-dir` / `ANTHILL_CACHE_DIR` / `anthill.toml` / XDG default; canonicalised paths for repo-hash so symlinks do not split caches. Two-layer transitive-dep guarantee: emitted_smt_lib bytes catch changes that surface in emission output; rule_dep_hash + fact_dep_hash catch transitive changes that do not (e.g. dep elided as dead code). Property: changing any transitively-referenced rule body or fact field MUST invalidate the dependent proof's cache key at any depth. CLI flags to wire on the scaland CLI (whichever crate ends up driving prove): --no-cache, --refresh-cache, --show-cache, --gc-cache <days>, --stats, --cache-dir. Implementation note: do NOT reuse requires_chain for dep-hashing (wrong primitive — walks sort-requires typeclass relations); build a fresh transitive walker over rule bodies and reuse the dep collection already populated during emission, content-hashing canonical body terms and referenced facts' canonical fields combined in sorted-by-QN order. Acceptance: sbt test green; second run of the comm_delay_max round-trip reports cache hit and skips Z3; regression test covering edit-of-transitively-referenced-fact invalidating a dependent proof's key (the headline correctness test from rustland's WI-096).
