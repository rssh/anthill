## Description

Operation-call-model: per-target codegen for requirement slots. Per docs/design/operation-call-model.md §'Codegen', each target picks how to render the requirement channel: Rust as &impl Trait or monomorphized; Scala as using clause; C++ as template-deduced argument; Lua as positional. Currently anthill has a Rust codegen pass (codegen/rust.rs) that emits trait/struct/enum from anthill specs but doesn't account for requirement_at_current / requirement_at_sort yet. This WI lands the codegen-pass extension: (a) Rust target emits leading &impl Trait params for sort-level requires; (b) op-level concrete dispatch (Pin-now) emits direct calls to the impl; (c) op-level Defer-to-requirement emits trait-method dispatch on the leading param; (d) requirement_at_sort projections become field accesses on the impl trait's associated type / Self::Requires; (e) codegen tests for each rewrite case. Out of scope (future WIs): C++, Lua, Scala targets. Acceptance: cargo-test green; new codegen tests pin Rust output for Examples 1, 4, 7 from operation-call-model-examples.md. Reference: docs/design/operation-call-model.md §'Codegen'. Depends on WI-222 for the IR; WI-223 for any runtime-aware codegen choices. ~300-500 lines.
