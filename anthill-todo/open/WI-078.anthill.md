(h) RE-SCOPED (user, 2026-10-17; docs/design/037-implementation.md, decision D3, step 3). Handler scoping is now proposal 037 §5.2. The implementations in force are an installation map: a persistent map from a base sort to an implementation, read only when a resource is made or mounted. (h) becomes its host entry and wrapping: Interpreter::with_installed(sort, implementation, f) keeps the current version, sets the new one, runs f, and restores the kept version whatever f returns. An implementation installed over a version may forward to the entry it replaces. Nothing is taken out of an entry while it runs, unlike EffectRegistry::take_for_invoke. The anthill-level installing operation, a higher-order operation whose frame works as Error.reify's does, is (h)'s later half: it needs an anthill value that is an implementation (037 §4.3), and its name and signature are 037 §10's open question.
