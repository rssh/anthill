## Description

share frame locals via Rc to eliminate per-sub-expression clones. eval_nested (eval.rs:~487) clones the parent's locals SmallVec every sub-expression; apply_closure clones captured env every call; reduce_lambda captures full parent locals (not free vars). Fix path: wrap locals in Rc<SmallVec<...>> so clone is a refcount bump. A principled follow-up is free-variable analysis on lambda body to capture only what's used, but the Rc fix is the cheaper first win. Benchmark driven — land after WI-053 compile-caches.
