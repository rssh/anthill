## description

Implement the `Branch` effect — value-level non-determinism in eval. WI-050 stubs it as UnhandledEffect; the runtime is still a placeholder (`eval/effects.rs:42`, `:438` — WI-075 delivered `push_choice`, the SUBSTRATE, not the effect).

SPEC: `docs/proposals/027.2-branch-from-streams.md` (Draft), which SUPERSEDES this ticket's original mechanism sketch. Kept for the record, now superseded: "(2) an operation returning multiple values pushes alternative frames; the activation stack forks. (3) at resolution points one branch proceeds; on fail() the saved alternative resumes." 027.2's shape instead:

(1) `reflect(s: LogicalStream[T]) -> T effects Branch` is the ENTRY POINT — each element of the stream becomes a branch, the empty stream is `fail()`. `branch(a, b)` is `reflect(stream_of(a, b))` and `fail()` is `reflect(empty)`, so the two-way form is the 2-element special case, NOT a separate mechanism. It rides the existing lazy-choice substrate (`push_choice` / `SearchStream`, proposal 033, WI-075 Verified) — n-ary entry point, no new choice substrate.

(2) SOLVERS ARE `reify` HANDLERS, AS FIRST-CLASS VALUES: `all` / `one` (strict iota) / `once` / `beam` (= 027.3 `ScoredBranch`, reused not re-specified) / `oracle`, installed via `provide`. A `Branch` with no enclosing solver is a LOUD load/type error — nondeterminism never leaks past a consumer. Users can define their own solver with no grammar change.

(3) THE ONE GENUINELY-NEW RUNTIME PIECE is the eval-to-SLD SWITCH: suspend the concrete evaluator at the goal, drive SLD, and MULTI-SHOT resume the continuation once per solution. Needs `StepOutcome::Suspend` — today `StepOutcome` is `Done | Continue | Deliver` (`eval/eval.rs:27`) — returning from `run()` with the activation stack intact plus a resume entry; the nearest existing shape is `Done`, which differs only in leaving the stack EMPTY. Plus COORDINATED BINDING: the interpreter keeps its suspended stack and the RESOLVER frame (`ResolverFrame`, `kb/resolve.rs`) holds only a resume handle it calls back, so the resolver never embeds eval types. `Clone` on `Frame`/`ActivationStack` is ALREADY DELIVERED (WI-078 Phase A/a, `eval/frame.rs:164`); the snapshot/resume protocol is WI-069.

(4) Surface desugar `match <solver> case <goal>` / `let <goal> = <solver>`, reusing the existing `case` / `let` binders — no new grammar.

WARNING, from WI-455's OWN feedback: 027.2 and 047 both cite WI-455 as the precedent for `StepOutcome::Suspend`. THAT PRECEDENT DOES NOT EXIST. WI-455 built `StepOutcome::Dispatch`, proved it green, then DROPPED it — an OpRef application now resolves in ONE HOP by construction, so there was no chain left to hand back to `run()`. Introduce `Suspend` on its own merits.

STATE ACROSS BRANCHES: governed by 047 §8 ranking — a resource ranked BELOW `Branch` survives backtracking, ranked ABOVE it is snapshotted and undone via `register_undo`. `External` admits NEITHER rank, so a `Branch` region may not perform it (054; the co-occurrence gate is DELIVERED, WI-701). Read the world before the search, search over tracked state only, write after the solver commits.

REQUIREMENT DICTIONARIES COME FREE IF WI-1040 LANDS FIRST — a SEQUENCING NOTE, deliberately NOT a dependency edge. Under WI-1040 a dictionary is an ordinary term bound in σ, and each branch has its own σ, so multi-shot resume gets per-branch dictionaries with no per-branch copy and no undo machinery (a dictionary is immutable). If Branch lands first, a dictionary inside a branch region simply re-derives per branch — correct, just wasteful. Design: `docs/design/requirement-channel.md` §7.

027.2 OPEN QUESTIONS to settle when picked up: the coordinated-binding handshake and resume-handle ownership (who holds the suspended stack, who re-enters); whether `reflect` takes the cheap `push_choice` path for the common finite-stream case rather than a general shift/reset; the solver `run` signature vs an incremental Observer interface; nested `provide` scope vs the 047 §8 rank table; `one` degeneracy when more than one solution exists (default: strict iota).

OUT OF SCOPE: the pure-stream layer (052 — DELIVERED as WI-714); the scored solver's internals (027.3, used here as the `beam` instance); general resumable effects beyond the Branch slice (WI-069 owns snapshot/resume as its own capability); effect-row discharge typing (WI-329).

ACCEPTANCE: `reflect` over a finite stream branches and a solver reifies the region — DRIVE it (run the operation, assert the collected solutions), not "it loads clean"; `fail()` backtracks; a body inside a branch RE-ENTERS search (the nesting case that distinguishes this from 052); a `Branch` with no enclosing solver is a loud error; each test says which case fails when the change is backed out. `cargo-test` green via `rustland/scripts/test.sh`.
