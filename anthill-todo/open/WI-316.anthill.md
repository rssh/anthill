## Description

Region escape analysis: structural reachability through returned named-sort fields (proposal 046 slice). WI-314's result_type_admits_region (rustland/anthill-core/src/kb/region.rs) inspects only the return type's OWN structure — it catches a region in direct / tuple-field / list / parameterized-type-arg / bare-type-var position, but MISSES a fresh region reachable solely through a returned NAMED sort's field (e.g. `-> Pair` where `Pair` has a `Cell` field): that Modify[result] is masked (silent unsound drop, contradicting the intended over-approximation). Unreachable in the current stdlib (no op returns a fresh-cell-bearing named sort), so deferred from WI-314 and documented in the region.rs NARROW-SLICE LIMITATION note. FIX: extend result_type_admits_region to descend into a returned sort's entity field types — resolve the sort, recurse over each variant's field types, with a visited set (recursive sorts) and type-argument substitution (parametric sorts like Pair[A] whose field type A is bound to Cell at the use site). This is the structural-reachability part of 046's region analysis. ACCEPTANCE: an op make(n) -> Pair = mk(Cell.new(n), n) where Pair has a Cell field, WITHOUT effects Modify[result], is rejected with undeclared-Modify[result]; the parametric Box[A]-with-Cell-field case is handled via the binding; full cargo-test green. Sibling to WI-315 (plugin-engine promotion).
