## Description

Diagnostic wart in the WI-320 effect-row-param anchor (surfaced by the WI-698 smoke, 2026-07-12; INDEPENDENT of External, hence deliberately NOT a WI-698 umbrella dependency). A user-namespace `effects X = ?` declaration REQUIRES `import anthill.prelude.EffectsRuntime`; without it the load fails with a confusing `does not provide EffectsRuntime` instead of naming the real cause. MECHANISM: the `effects X = ?` desugar emits `requires EffectsRuntime[Effects = X]`, and the provider-requires check (WI-343) exempts that anchor BY SYMBOL IDENTITY (rustland/anthill-core/src/kb/typing.rs, around line 10836). Without the import the user-namespace occurrence is a DIFFERENT Symbol, the exemption misses, and the check reports the anchor as an unsatisfied requirement of the user sort. FIX -- pick at implementation time: resolve the anchor by canonical NAME rather than by imported-symbol identity; or auto-import the anchor at the desugar site; or, as a minimum, emit a targeted diagnostic naming the missing import as the cause. WORKAROUND today: import it explicitly -- rustland/anthill-core/tests/include/wi698_row_param_refinement_test.rs carries the import, with a comment, for exactly this reason.
