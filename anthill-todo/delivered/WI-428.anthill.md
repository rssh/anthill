## Description

Typer+loader: RigidTypeProjection -- the TYPE-receiver projection (P.Key / MemStore.Key / Storage.Key sugar), the type-keyed sibling of ExprCarried. Design: path-dependent-types.md sec.5.3 (decided 2026-06-10 w/ user). FORM: RigidTypeProjection(requires, var, member) -- 'requires' = the CANONICAL bound application (named-sorted; positional application is sugar for names), NOT the bare spec symbol, so two same-spec bounds over distinct bindings stay distinct identities (type-side twin of WI-419); 'var' = the carrier's actual type-var TERM (+ source name for display), so delta-on-binding is an ordinary sigma walk -- instantiation grounds the projection through project_type_member with no bespoke machinery, and cross-call neutral threading holds for free for this head; 'member' = the spec's declared param NAME (identity by name, never position). Strictly (requires, member) is the identity; var is recoverable as the carrier binding, kept for display + the WI-403 lift. FORMATION (rigid by construction -- only the stuck case is ever stored): (1) delta at formation: a manifest receiver (MemStore.Key, a bound alias) grounds immediately, never stored; (2) delta THROUGH the bound: a member the bound application binds grounds through it (requires Storage[P, Key = String] => P.Key = String); only bound-OPEN members form the projection; (3) a member the spec does not declare = LOUD error. Well-formed by construction -- no env needed to validate (contrast ExprCarried's threaded declaring-sort). ZETA: equal iff same member + same canonical application + carrier vars in the same sigma-class -- a CHECK, never a binding (non-injectivity unchanged). BARE-SPEC SUGAR: Storage.Key is NEVER a type by itself -- desugars at classification when exactly ONE carrier of Storage is in scope (value carrier -> ExprCarried(s, Key); type-param carrier -> RigidTypeProjection; inside the declaring sort = qualified spelling of bare Key); two carriers -> loud ambiguity error. REFLECT: new TypeExtractor entity in stdlib/anthill/prelude/sort.anthill (the self-hosted typer must case over neutrals). HOST: WI-403 becomes a transliteration -- (Convert[A=X,B=Y], X, M) -> <X as Convert<B=Y>>::M (carrier param -> Self, other bindings -> equality bounds, member name -> associated-type name). INVARIANT (sec.5.3 groundedness stratification): rigid neutrals are TYPING-TIME citizens only -- interface-rooted (escape-free, WI-401), never in asserted facts; runtime Type values stay ground (eval delta-grounds off the dynamic receiver); extract stays total.
