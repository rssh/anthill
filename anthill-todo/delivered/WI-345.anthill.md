## Description

Loader warnings channel: non-fatal diagnostics from load passes. Add a warnings vector to the loader (load.rs) parallel to LoadError, surfaced via LoadResult, so passes can emit non-fatal warnings without failing the load. Prerequisite substrate for lint-style diagnostics (e.g. the requires-shadow warning). See docs/kernel-language.md §8.7 'Operation override'.
