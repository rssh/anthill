## description

FileStore retract: actually modify files at flush time. Implementation: Store::retract gains a kb argument and buffers the canonical printed form of the rule head. At flush time, parse each affected file, drop fact blocks whose head canonicalizes to a buffered retract, then append persisted writes. Inter-fact text outside fact blocks (comments, blank lines) is preserved via byte-range tracking; comments inside a fact block are not preserved. Persist plus flush is idempotent. Tests added in anthill-core/tests/persistence_test.rs: retract_unknown_rule_is_noop, retract_drops_fact_block_from_disk, retract_then_persist_replaces_in_place, retract_preserves_inter_fact_text, flush_is_idempotent_after_retract. Design: examples/github-todo/docs/anthill-migration.md section 5.1.
