## Description

WI-292 PHASE 2 -- container-sort requires firing (Set/Map). member/insert/subset/union (Set) and get/put/contains/remove/size (Map) are body-less spec ops of a requires-bearing sort, but their carrier is an ELEMENT (or the abstract container S) that does not 'provide' the container, so the WI-292 carrier-provides check leaves them dormant. They need a DIFFERENT mechanism: the sort's type-param element provides the sort's requires spec (a Set[T] needs Eq[T]) -- the element's Eq dictionary, not the container providing itself. ALSO the reducing stdlib rules (member(?x,insert(?s,?x))<=>true, union(empty,?s)<=>?s, ...) currently carry NO [simp] tag, so the WI-292 directional-rewrite gate skips them; tagging the genuinely-reducing ones [simp] (NOT commutativity/assoc) is part of this. Design separately from spec-op dispatch.
