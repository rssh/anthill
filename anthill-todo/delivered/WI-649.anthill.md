## description

reify/reify_value cyclic-substitution (sigma) stack overflow: the reification recursion has NO cycle guard / depth cap, so a cyclic sigma overflows the host stack instead of erroring LOUDLY or delaying. reify (term-Fn path, mod.rs ~2519) recurses through sigma-bound subterms unguarded; since WI-629, reify_value (mod.rs ~2630, via reify_value_children) also recurses into Value::Entity/Tuple children unguarded. A cyclic binding v |-> Fn(...v...) or v |-> Value::Entity{...v...} thus stack-overflows. PRE-WI-629 an Entity carrier was ACCIDENTALLY cycle-safe (reify_value fell to other.clone(), no descent); WI-629's deep reification (required for NAF verdict honesty over Value-carried not/or inners) removed that accidental safety, making Entity match reify's already-unguarded term behavior. Cyclic sigma is a KNOWN limitation: mod.rs ~3233 documents 'a cyclic sigma overflows reify/fingerprint' and resolve.rs ~1185 defends list_to_vec with a seen-set. The COMMON answer path is defended by the WI-624 occurs-check on answer_links, BUT the Value-carrier bind paths (bind_waking for external/routed rows, mod.rs ~1956; bind_value, subst.rs ~245) are NOT occurs-checked, so a routed-store row (or any future non-occurs-checked Value bind) that reaches reify_value could in principle trigger the overflow. Violates the loud-over-silent principle (a stack overflow is neither honest nor bounded). FIX DIRECTION (systemic, both functions so term + entity paths stay CONSISTENT -- a bespoke guard only in reify_value's Entity arm would be an inconsistent band-aid): (a) occurs-guarded / depth-capped recursion -- a seen:HashSet<VarId> or a REACH_DEPTH_CAP like value_reaches_eq_override's 256 -- returning a LOUD error at the cap; and/or (b) occurs-check the Value-carrier bind paths (bind_waking) so a cyclic sigma never forms. Regression test: construct a cyclic sigma (v |-> Entity/Fn containing v) and assert reify + reify_value surface a bounded error, not a crash. Discovered by the WI-629 /code-review (correctness finder A), deferred as out of WI-629 scope.
