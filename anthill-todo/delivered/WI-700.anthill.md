## Description

Effect-row SOUNDNESS HOLE, GENERAL -- not External-specific (surfaced by the WI-698 smoke, 2026-07-12). At EXPLICIT row-instantiation call shapes -- `op[EffP = {...}](callback)` -- the DECLARED callback row is not enforced, so a non-empty effect row escapes into an operation declaring `effects {}`. Two independent probes, both pinned TODAY-AS-LOADING in rustland/anthill-core/tests/include/wi698_row_param_refinement_test.rs, both to be FLIPPED to expect-reject by this WI: (a) `lacks_unenforced_at_explicit_instantiation_today` -- `shield[EffP = {Outside}](poke)` loads although shield declares its callback `-Outside`, so the lacks-constraint parses but does not enforce; (b) `row_conformance_unchecked_at_explicit_instantiation_today` -- `shield[EffP = {}](poke3)` loads although poke3 declares `{Outside}`; there is no self-contradictory row in (b), so the eventual reject must come from actual-vs-declared conformance ITSELF, not from row self-inconsistency. ROOT CAUSE, localized: `validate_callback_effect_row` (rustland/anthill-core/src/kb/typing.rs:14393) IS wired into the ordinary call path -- both argument loops call it (typing.rs:5983 positional, typing.rs:6011 named) -- but its open-vs-closed decision reads a declared row whose tail is a row PARAM (`{EffP, -Outside}`) as OPEN, hence ABSORBING, and never resolves the explicit `[EffP = {...}]` instantiation through the substitution first. Its own doc comment already claims bound row-tail resolution; the explicit-instantiation binding does not reach it. FIX: resolve an explicitly-instantiated row param before the open/closed decision. This escape exists today for EVERY effect -- Modify, Error, Clock -- so it is worth fixing on its own terms; the WI-698 External is merely its first demanding client (the 054 Branch gate is a `-External` lacks-constraint and therefore rests on this check, hence WI-701 depends on this item). RISK / why this lands EARLY: it is a BEHAVIOR CHANGE -- code that loads today will stop loading -- so budget for fallout across existing explicit-instantiation call sites in stdlib and tests, and review the blast radius. ACCEPTANCE: both `*_today` tests flipped to expect-reject and green; full cargo-test green.
