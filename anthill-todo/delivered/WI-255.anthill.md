## Description

Acceptance: typing_pass_spec_parses_and_loads passes on the default test stack with no std::thread::Builder.stack_size workaround; full workspace tests green. Approach: convert the type_check_node / check_* family to a work-stack walker mirroring the post-WI-253 materializer (Visit/Build pair, post-order assembly), threading the TypingEnv through Build frames since let/match/lambda extend the env when entering their body.
