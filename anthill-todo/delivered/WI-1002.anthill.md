## Description

Update docs/kernel-language.md after proposal 059 implementation lands. The kernel spec is canonical; the proposal retains measurements and rejected alternatives.

DOCUMENT: definitions of main entry, secondary entry, ordinary namespace, entry identity by file, member and dispatch surface; classification by address after the finished program is known; R1 single type declaration; R3 default-deny content rules; R4 operation and capture rules; R5 remedies; and R6 order-independent rule-head binding. Record the whole-program classification consequence: an ordinary namespace becomes a secondary entry if another file declares a sort at that address.

CURRENT R4 POLICY: one operation declaration per name and scope, already enforced by WI-1049; an operation introduced by a secondary entry must be fresh and have a runnable Anthill body; a secondary entry never fills a bodyless declaration; and a declaration may not capture an existing meaning unless it is an override or distinguishable refinement. Do not restore the superseded WI-998 fill policy.

SYNC RELATED SPEC TEXT: reconcile section 8.7 scoped instance selection with the whole-program premise, explain how a namespace at a carrier address differs from an unrelated namespace-level operation for backing, update the WI-1048 capture and refinement wording, and record file-local imports from WI-995.

Do not copy measurements or design argument into the canonical spec. Run rustland/scripts/test.sh if executable examples or tests change.
