## Description

WI-204 enabler: Modify-transitivity in effect typing per proposal 037. Blocker for WI-204's mutating cmd_X (cmd_add, cmd_claim, cmd_deliver, cmd_verify, cmd_delete, cmd_feedback). Today FileBasedWorkitemStore.commit's body calls persist(b, w, _) where b = wis(backend) — i.e. b is reachable from s via the wis(backend) field. persist's effect Modify[T = store] becomes Modify[T = b] at the call site (WI-209 substitution). commit declares effects {Modify[s], Error}. Typer rejects with 'undeclared effect: Modify[T = b]' because Modify[T = s] doesn't transitively cover Modify on s's reachable subterms. Per proposal 037 §Modify-transitivity, Modify[s] should subsume Modify on any s.field reachable through the cell's V. Fix: extend the typer's effect-row containment check (kb/typing.rs check_apply / merge_effects) so Modify[T = X] covers Modify[T = Y] when Y is a subterm of X reachable through declared entity fields or pattern bindings. Acceptance: cargo-test green; FileBasedWorkitemStore.commit type-checks with effects {Modify[s], Error} (no 'undeclared Modify[T = b]'); new typing test pins the transitive coverage rule. Out of scope: full proposal-037 effect handler discharge — this WI just covers the typer-side containment check.

### 2026-05-10T19:15:00Z — feedback — claude

WI-219 reproduces no failure on current main: anthill-todo/store.anthill typechecks cleanly. The case the description targets (Modify[T = b] surfacing when b is pattern-bound from s) is already handled by the local-resource mechanism added in commit 260af54 (Implement effect scoping: local let-bound resources don't propagate). The match-case binding in `case wis(b, c) -> persist(b, ...)` calls `env.declare_local_resource("b")` (typing.rs:1652), and `external_effects` filters Modify[T = b] out before checking against declared effects. Functionally equivalent to the transitive-coverage rule the WI proposed. Test rustland/anthill-core/tests/wi219_modify_transitivity_test.rs pins this: 3 cases (in-test pattern, stdlib-persist call, full project store.anthill) all pass without code changes. Marking Delivered. The transitive-coverage rule from proposal 037 §Modify-transitivity remains a future concern only if anthill ever adds direct field projection (s.field outside pattern matching) — currently all subterm extraction is via match, so local-resource handling suffices.
