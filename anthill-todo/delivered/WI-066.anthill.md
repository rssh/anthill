## Description

Encode partiality of integer division as Error-effect. Currently Int.div and Field.div errors on divide-by-zero only at runtime (EvalError::DivisionByZero). Add Error[DivisionByZero] to signatures: Int.div, Int.mod, Int.rem, Field.div all grow effects Error[DivisionByZero]. Add sort DivisionByZero payload alongside MatchFailed in effects.anthill. Float.div stays pure (IEEE 0.0/0.0=NaN, 1.0/0.0=Inf are defined values, not errors). Downstream: callers using / on Ints must declare Error[DivisionByZero] in their effect rows OR handle it. Typer may need to thread this; existing tests might need updates.
