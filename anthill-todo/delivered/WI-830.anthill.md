## Description

Declarative extent binding with an explicit role: name each functor supplier per functor, not per process. THE REGISTRY MOVE ALREADY LANDED (WI-919 and siblings) -- `ExtentRegistry` (rustland/anthill-core/src/kb/extent.rs) holds BOTH `mounts` (owners) and `mirrors` + `mirror_monotonicity`, and `Interpreter::register_mirror` (eval/mod.rs:465) is a bare delegate to `KnowledgeBase::register_mirror`. So FileStore is ALREADY an explicit mirror and STAYS one; this item does not change its semantics. Why it must not become an owner (proposal 057, Mounts/single-owner/roles): an owner delegates reads to `query` with the resident subtree required EMPTY (register_extent_owner refuses a functor that already has resident facts/rules, extent.rs:449), so FileStore would have to reimplement the discrim tree as a query engine over parsed text, for an extent that is fully in memory anyway (workitems.anthill = 4615 lines parsed at startup); ownership additionally makes a bodied rule on an owned functor a LoadError; and ownership is per-functor exclusive while a file store is per-FILE -- one workitems.anthill carries four functors (Feedback 1106, WorkItem 1098, Tag 273, StoreFormat 1). Ownership buys laziness/partiality, which is WI-437 GitHub/SQL territory, not a local text file. WHAT IS LEFT = THE BINDING: a declarative fact naming, per functor, WHICH store supplies its rows and in WHICH role (owner | mirror), read at registration by a host factory mapping the declared store sort (FileStore/SqlStore/...) to its Rust ExtentSource/Store constructor. Per 057 Configuration+bootstrap: a binding fact, NOT `route` rules (the catch-all rule route(?) and the vestigial route op go); writability keeps materializing from fact_monotonicity rather than a new field. Retires the placeholder `ExtentRegistry::sole_mirror_key` (extent.rs:552, sole caller read_stored_facts extent.rs:1132), which today can attach a mirror to a resident StoredRow only when EXACTLY ONE is registered and otherwise errors AmbiguousResidentMirror -- the direct blocker on registering a GitHub owner alongside the file mirror. The fixed IndexedFileStore construction in rustland/anthill-todo/src/main.rs (~763-816) becomes one declared binding. Prerequisite for WI-437 pluggable backend selection.
