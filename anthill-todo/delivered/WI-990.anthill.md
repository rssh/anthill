## description

SCALAND: `ScopeId`'s MINT SURFACE HAS TWO HOLES — A SYMBOL FROM THE WRONG TABLE, AND A NAME UNIVERSE NEITHER MINT COVERS. WI-976 made scope-hood a type; these are what the type does not yet state. (1) CROSS-TABLE SYMBOLS. `ScopeId.of` is total over `TermSymbol`, but a `TermSymbol` only means anything relative to ONE `SymbolTable`, and the loader threads two side by side — `kb.symbols` and the per-file `fileSym` — in nearly every signature. MEASURED: `kb.scopeDisplayName(ScopeId.of(foreignSym))` throws `IndexOutOfBoundsException`, and `kb.scopeTerm(ScopeId.of(foreignSym))` degrades SILENTLY to a name term for a different symbol. `ScopeId.of(imp.path.last)` type-checks today; all 12 current main-tree mints happen to use `kb.symbols`, so this is latent, not live — but it is the same promise-carried-by-hand the ticket removed, relocated from Int-vs-TermId to which-table. Minting THROUGH the table (`symbols.scopeOf(sym)`) closes it. (2) `scopeByQualifiedName` THROWS on a miss with no error channel. All four callers are private `Prelude` methods returning `Unit`, so a miss aborts KB bootstrap with a stack trace rather than a diagnostic; its unreachability rests on nothing but the statement ORDER inside `Prelude.register`, with no test naming that order load-bearing. Eight lines away, `registerBuiltinTags` handles the identical "stdlib namespace not registered" condition by DEGRADING — two opposite policies for one condition in one file. And `scopeByQualifiedName("_global")` throws, because `_global` is interned and never defined: the KB exposes two scope mints over two DISJOINT name universes, and neither one can name every scope. WORK: (1) move the mint onto `SymbolTable`; (2) pick one policy for a missing stdlib scope and make `Prelude`'s ordering dependence either impossible or asserted. ACCEPTANCE: for (1), that `ScopeId.of(fileSym-symbol)` does not compile, asserted with `typeCheckErrors` as `ScopeIdentityTest` already does for the Int and TermId cases; for (2), a test that reorders `Prelude.register` (or asserts the invariant it needs). Say at the site which test fails when the change is backed out. Found by code review of WI-976/WI-983 (2026-08-04). Related: WI-976, WI-987.
