## description

Compile-time macros: extend the [simp] rewrite engine to CALL macro operations (proposal 043.1, docs/proposals/043.1-compile-time-macros.md). A macro = an operation marked [macro] whose params/result are occurrences (NodeOccurrence / reflect Expr) that the [simp] engine EVALUATES AT COMPILE TIME when a fired rule RHS calls it -- the user-authored generalization of 043 section 4.2 expression-accepting builtins (min_sort/constant_fold/reflect-Expr builtins). REVISES 043 non-goal (No new macro concept), narrowly: NO kernel/grammar change; a macro is an ordinary op + the existing [simp] firing phase + a marker. MOTIVATION: 043 walls the expression-accepting bridge to ENGINE builtins only and never enumerates them; there is no way for user code to author a compile-time syntax-to-syntax transform. VERIFIED BASELINE (absent today): a user op m(x: NodeOccurrence) -> NodeOccurrence placed in a [simp] RHS is typed as an ORDINARY value-domain call -- the pattern var arrives as its evaluated-value type (Int64), not the occurrence; substitute_to_occurrence builds the RHS by template substitution only, never evaluating the op. MECHANISM (3 pieces): (1) MARKER -- parse/store a [macro] attribute + KnowledgeBase::is_macro(op) [lean: attribute; open alternatives = signature-domain classification per 043 section 4.2, or a macro keyword]. (2) FIRE HOOK -- in kb/simp_rewrite.rs try_fire, after substitute_to_occurrence (which ALREADY reuses each matched pattern-var child occurrence in place, so m(?a,?b) builds apply(m,[occ a, occ b]) with the real occurrences as args), detect a macro-head result and route it through compile-time eval instead of leaving the template. (3) COMPILE-TIME EVAL -- reuse the WI-625 scratch-interpreter precedent (bodied op evaluated at compile time); bind the macro params to the argument occurrences as Value::Node; run the body (which reads args via reflect sub_occurrences/occurrence_term/the Expr entities and builds a result via make_fn/as_term); take the Value::Node result; splice it; continue the bottom-up rewrite fuel-bounded (043 section 4.5) with the Synthesized.from ancestor-loop check. PURITY/TERMINATION: macros run at compile time so they must be pure + terminating (043 discipline extends unchanged); a macro may raise a compile-time Error diagnostic at the redex span; open = load-time reject of an impure effect row. NOT WI-189 quote: a macro CONSUMES existing occurrences (the lambda already IS the quotation), it does not manufacture un-evaluated code, so staging is NOT a prerequisite. SCOPE: occurrence-side (typer call site) only -- a Term goal at the logical-engine site is not a syntax bracket. PREREQUISITE FOR: WI-714 / proposal 052 where-to-guarded + join-to-conjunction row-lambda crossing (where(r, c -> eq(c.x,1)) becomes guarded(r.query, eq(?col_x,1)) via a [macro] guarded_of that reads the lambda body occurrence, maps c.x to the column logic-var, eq to a goal atom). ACCEPTANCE: a minimal [macro] that rewrites a marker occurrence at compile time (the inverse of the verified-absent baseline) passes; the reflect occurrence read+build API is audited/closed for the where/join transform; cargo-test green via rustland/scripts/test.sh. Rust-only (simp engine + typer; scaland has no simp engine).
