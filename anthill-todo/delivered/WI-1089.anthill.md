## description

AN IMPORT BINDS THE NAME IT WRITES, AND OPENS ONLY WHAT IT NAMES. DELIVERED, both implementations + spec. USER RULING (2026-08-12): `import a.b.C` puts `C` in scope — not `a.b`, and not `C`'s members. The ticket was filed over three disagreeing answers; the ruling is that there is only one, and it is the one every mainstream language has: `import a.b.C` / `use a::b::C` binds one name. The other two were rustland artifacts, not designs. (1) THE PLAIN FORM SPLICED THE TARGET'S SCOPE IN as a resolution parent, so a plain import made the target's members bare-callable — removed; the alias is the whole of what the line does. Note kernel-language.md 4.4 ALREADY said this ('It does not add the imported sort's scope as a parent — importing Eq does not make eq/neq directly accessible') while 8.6 said 'include a.b' and the code did a third thing; scaland already implemented the rule. (2) THE PARENT WALK RE-ENTERED AN IMPORTED SCOPE'S ENCLOSING CHAIN, so any import also delivered the module around what was imported, and the module above THAT — which is what made (1) look like 8.6's text: the reach was an artifact of the walk and vanished whenever the imported name had no scope of its own (WI-993 measured that). Stopped in both implementations (`EnclosingLinks` / `enclosingStopped`), as a PATH property that stays set for the rest of the walk. THE STOP IS FOR AN EDGE AN IMPORT ALONE JUSTIFIES (`parent_edge_is_import_only`), and getting that wrong was the one real bug: keyed on 'an import is AMONG the writers', it cut two ordinary programs — `namespace a.b { import a.* }`, where the pair is ALSO the enclosing edge, lost `_global` and the prelude so a bare `Int64` stopped resolving; and `requires Spec` beside `import Spec.*`, one edge with two writers, lost what the `requires` reaches, i.e. an additive line took a name away. Both found by /code-review, both now regression rows. Scaland additionally decides the mode per PARENT rather than per inclusion, so the answer no longer depends on the order the two clauses are written in (also /code-review). No capability is lost — only spellings change. THE ALTERNATIVE READING (C's members come too, container closed) cost 5 fixtures and was rejected: it keeps rustland != scaland and contradicts 4.4.
