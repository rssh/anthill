## Description

Lightweight cross-namespace import for rule-defined predicates. PROBLEM: a predicate defined only by rules (e.g. type_compatible in anthill.reflect.typing) cannot be imported from another namespace -- import anthill.reflect.typing.{type_compatible} fails with unresolved-import. process_imports Selective arm (rustland/anthill-core/src/kb/load.rs ~955) resolves a name only via by_qualified_name + resolve_in_scope; rule heads register no importable symbol there (only sort/entity/operation + registered builtins do). is_entity_of imports ONLY because it is a registered builtin (BuiltinTag::IsEntityOf); type_compatible and refines are pure rule heads, invisible to import. The export keyword is a no-op (proposal 044, load.rs:505, visible-by-default). Yet the predicate IS resolvable everywhere else: rule_id_by_qn (mod.rs:1706) resolves a qualified name label-first then by_functor, and the resolver matches goals by functor symbol -- so the gap is purely that the import path never consults the rule indices. TASK: in process_imports ImportKind::Selective arm, add a fallback -- when a selective-import name resolves to nothing as sort/entity/operation/builtin, try resolving it as a rule-head predicate (try_resolve_symbol(qualified) then by_functor non-empty, or rule_id_by_qn) and add_import aliasing that symbol. A few lines; no new construct, no declarations, no closure. MOTIVATION: lets a self-hosted relation (the typing relation synth/check/wf_type in docs/proposals/typing_pass_spec.anthill) live in its own namespace and import type_compatible, instead of co-locating into anthill.reflect.typing (current workaround). SCOPE: extends proposal 044 (unified name resolution) to rule-predicate heads; mirror in scaland for parity. This is the minimal FQN-access for rule-defined predicates, NOT the full declared/closed-relations feature (deferred vision in docs/brainstorms/declared-relations.md). NOTE: load-only -- does NOT address the separate Expr-as-data resolver panic (open_debruijn_node in node_occurrence.rs) that blocks running typing rules. ACCEPTANCE: importing a rule-defined predicate from another namespace resolves, and a goal through it resolves cross-namespace; new test; cargo-test green; scaland parity.
