## description

A NAMESPACE-LEVEL entity carrier never keys the semantic-equality dispatch index, so its `eq` supplier is silently ignored and equality answers STRUCTURALLY. The index build (`build_eq_dispatch_index`, rustland/anthill-core/src/kb/load.rs) derives its carrier list from `sorts_and_own_ops`, i.e. from `anthill.reflect.SortInfo` facts — and `emit_sort_info` has ONE caller, `load_sort_with_body`, so ONLY a `sort … end` block emits one. A free-standing `entity binding(n: Int64, note: Int64)` written at namespace level (as `stdlib/anthill/cli/parse.anthill` and `examples/github-todo/domain.anthill` do) is its own carrier with no `SortInfo`, so the walk never reaches it. MEASURED with a control pair (rustland/anthill-core/tests/include/wi837_witness_eq_dispatch_test.rs, `a_sort_wrapped_entity_carrier_keys_the_index` / `a_namespace_level_entity_carrier_does_not_key_the_index`): one otherwise-identical program with `fact PartialEq[T = C, eq = cEq]` where `cEq` answers true for ANY pair gives 1 solution when C is a `sort`-wrapped entity and 0 when C is a namespace-level entity. PRE-EXISTING and route-independent: the same walk has always fed the index, so the WI-625 gap-2 instance-fact route, the WI-616 own-member route, and WI-837's witness route all degrade identically for such a carrier. Two consequences worth naming: (a) the WI-664 lawful-Eq boundary classifier (`eq_derive::is_eq_boundary`) enumerates a DIFFERENT universe (`composite_sorts`, off the entity-field-schema registry), which DOES include the namespace-level entity — so after WI-837 the two share a PREDICATE but not a DOMAIN, and a namespace-level entity can be a lawful-Eq boundary whose `eq` never dispatches; (b) it is the safe direction (structural eq, no derived NonEq) but it is silent, which is what this repo refuses. ACCEPTANCE: the index build enumerates namespace-level entity carriers too — reusing whatever `eq_derive::composite_sorts` uses rather than a second hand-rolled walk, so the domain gets ONE owner like the predicate now has; the measured control pair above flips to 1/1 and its 'PINS A KNOWN GAP' premise is deleted; the WI-837 ambiguity refusal (`AmbiguousEqDispatch`) also fires for such a carrier — assert the diagnostic identity; blast radius checked, since every free-standing entity with an eq supplier becomes newly index-keyed (stdlib, examples/, anthill-todo/ all load clean and full workspace green via rustland/scripts/test.sh).
