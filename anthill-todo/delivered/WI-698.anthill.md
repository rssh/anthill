## Description

substrate: generic External effect -- ONE language-level effect marking dependence on state outside the tracked heap (forge/network, entropy, out-of-store filesystem): non-deterministic across calls, non-replayable, results never equational. Motivation (WI-437 design doc rustland/anthill-todo/docs/design/backend-github-coordination.md section 8.3): the Mirror carrier ops need coverage Modify/Error cannot express; the load-bearing case is a READ -- recent_issues(m) mutates nothing in-process, so today's convention types it Error-only (like WorkItemStore.lookup), but Error-only is honest for KB reads (KB changes only via tracked Modify) and dishonest for a forge read (another writer changes the registry between two calls with NO tracked mutation in between). Semantics: External revokes the pure-code licenses -- no re-run, no reorder, no dedup/CSE, no drop, no equational use; any non-empty row already pins sequencing, External adds precisely: two calls may disagree without any tracked Modify between them. Deliberately GENERIC, one effect not per-capability (no Mirror/Http/Db effects): the distinctions between external capabilities are AUTHORITY, which lives in carriers (the value you must hold; IndexedFileStore precedent) and later in a capability system if we build one -- so the row vocabulary stays stable as backends multiply. Scope: (a) declare the effect + row surface {External}; (b) typer threads it as an ordinary row member; (c) guard integration: fire_simp, op_defining_equations, synthesize_op_defining_rule(_at) DECLINE ops whose row carries External -- loud decline, not silent skip; (d) short proposal in docs/proposals/ recording the semantics + the effects-vs-capability split + why Console/Clock are left as-is for now (proto-External markers; folding/aliasing is a later decision); (e) persistence stays absorbed under Modify[s] (works today; honest External migration optional, later). First consumers: WI-437 increment 3 -- Mirror carrier ops typed {External, Error}, alloc_id/commit spec rows {Modify[s], External, Error}, fresh_token() entropy op. Value beyond the tracker: any future host binding (http, db, external tools) reuses the same effect.
