## Description

Proposal 035: free-standing parametric operations at namespace level. Today operations inside sort bodies inherit the sort's type parameters, but namespace-direct operations have no way to declare their own. Surface: `operation pair[A, B](a: A, b: B) -> Pair[A = A, B = B]`. Work: (a) grammar — extend operation_declaration to allow `[A, B, ...]` between name and `(` for type params; regenerate; tests; (b) converter — collect type param names into IR; (c) loader — register them as type params in the operation's local scope so `A` resolves to a fresh sort var inside param/return type positions; (d) typer — generalize over the declared params and instantiate them at each call site. Acceptance: `pair[A, B](a, b)` parses and typechecks at namespace level with the same semantics as the equivalent declaration inside a sort body; existing sort-nested operations still work. Driver: proposal 035 §Free-standing parametric operations; symmetry argument. Independent of WI-185.
