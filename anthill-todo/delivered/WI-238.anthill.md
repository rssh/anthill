## Description

WI-238 DECISION: resolved as option (B) — KEEP the WI-243 NodeOccurrence-synthesis substrate. A real production consumer materialized after this ticket was filed, so the keep/drop question is settled in favor of keep and no code change is required by this ticket. Background: at filing time the substrate (NodeOccurrence::synthesized_expr, PassId, OccurrenceOrigin::Synthesized, kb.register_pass) had exactly one caller — its own unit test — and the originally-intended consumer was moot. That original motivation was to wrap each req_insertion-emitted Term::Fn with a Synthesized origin so an unbound-var-in-requirement eval error could point at a source span; post WI-247/248/251 the eval instead reads real Apply NodeOccurrences from kb.op_bodies (with their own spans) and synthesizes the requirements channel at runtime via expand_dispatching_dict, never touching the emitter output, which now lives only in the test-only kb.dispatch_rewrites / dispatch_origin side-tables (the interpreter never reads it). What changed: the typer-phase [simp] rewriting engine (kb/simp_rewrite.rs; WI-277 / WI-278 / WI-283; proposal 043) became a full production consumer of the substrate. It calls kb.register_pass(anthill.kb.passes.simp_rewrite) to obtain a PassId and builds every rewritten RHS via NodeOccurrence::synthesized_expr carrying OccurrenceOrigin::Synthesized { from, by }, so when a [simp] equation fires LHS->RHS over an operation body the synthesized RHS inherits the redex source span plus provenance. The substrate is additionally consumed across kb/typing.rs and kb/node_occurrence.rs. Consequences: option (A) drop is off the table — deleting synthesized_expr / OccurrenceOrigin::Synthesized / register_pass / PassId now breaks the typer. Option (C) speculative req_insertion emitter migration is NOT done and stays out of scope: still no consumer, and dispatch_origin remains test-only (consumers wi204 / wi218 / wi222 / wi227 / wi231 / wi237 only). The consumer the substrate found is essentially the (B) outcome this ticket predicted (a pass that lifts forms into more primitive Expr with synthesized origin), realized as the [simp] equational rewriter rather than a let/match lift. Acceptance met: decision recorded (B); workspace cargo-test green independent of this ticket (the substrate ships with its [simp] consumer); description updated to match what shipped.
