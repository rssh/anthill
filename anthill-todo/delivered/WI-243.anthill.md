## description

Minimal substrate for synthesized occurrences. Adds: (a) PassId(Symbol) newtype — typed wrapper preventing accidental Symbol mixing, same 4-byte cost; matches existing ExprOccurrenceId(OccurrenceId) pattern at kb/occurrence.rs:40. (b) OccurrenceOrigin enum { Source, Synthesized { from: OccurrenceId, by: PassId } } — origin field on OccurrenceEntry (default Source for all existing alloc/alloc_expr paths). (c) alloc_synthesized(term, owner, from, by, is_expr) -> OccurrenceId — span inherited from `from`. (d) Public kb.register_pass(qualified_name) -> PassId — entry point any synthesizing pass calls at startup to obtain its PassId. Naming chosen: 'OccurrenceOrigin' (not 'Phase' — concept is provenance, not temporal phase) and 'Synthesized' (not 'Elaborated' — standard compiler vocab, avoids type-theory jargon). DISCOVERY during implementation: WI-235's let-hoist (the originally-intended first consumer) was removed in WI-237 Phase 2 / commit 333d4cf because the names-model migration made body-level construct_requirement deduplication unnecessary (dispatching dicts are now installed once into frame.requirements[__req_<spec>] at call site). WI-235-lineage cleanup included in this WI (per user's 'code clean, no unused code' directive): removed kb.op_body_overrides field + set_op_body_override / op_body_override accessors + eval::lookup_operation_body's override consultation (no producer remains); removed enclosing_op_sym field on TypingEnv + set/get accessors + the CallClass::ConcreteApplyWithin field (was set by check_apply but req_insertion destructured it as `..` and discarded — pure dead data flow). NOT added (deferred until first consumer materializes): PassRegistry struct of pre-resolved pass symbols; body_occurrence_of_op index. Both were initially planned for WI-235's hoist; with no current consumer they're speculative. When an actual synthesizing pass appears (WI-238 emitter migration, future elaboration), the registry + index get added then with the consumer that motivates them. PREREQUISITE for WI-238 (req_insertion emitter migration) and WI-242 (full Expr lift) — both reuse this substrate. Out of scope: WI-231 emitter migration (WI-238), Expr/Value::Expr/HandleKind::Occurrence removal (WI-242), dispatch_rewrites migration (WI-242). Acceptance: cargo-test green; OccurrenceStore unit tests verify alloc_synthesized stamps origin=Synthesized{from, by}, inherits span from `from`; alloc_default_is_source verifies plain alloc still stamps Source.
