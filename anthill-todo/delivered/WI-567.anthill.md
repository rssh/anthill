## Description

Refactor head into a total headOption + a guarded-Error head (a concrete proposal-048 Phase 4 subject). Provide BOTH: headOption(...) -> Option[T] (the safe/total form — absence is the value none) AND head(...) -> T @ { Error[EmptyList] :- isEmpty(...) } (the ergonomic form — returns the element directly; the 048 guard discharges to PURE where the typer can refute isEmpty, and stays a must-handle Error otherwise). Motivation: Option alone is sound but forces unwrapping even where non-emptiness is statically provable; the guarded head gives direct-T ergonomics that are statically safe-where-provable — strictly better than a throwing/panicking head. LOAD-BEARING SCOPING (derived in design discussion 2026-06-25): the guarded head belongs on the CONCRETE List, NOT the abstract/lazy Stream. Reason: the 048 discharge can only refute a guard via (1) literal abstract-interp on a visible constructor, (2) a verbatim-matching flow-fact in Gamma, or (3) KB resolution under step_cap. On a concrete List, isEmpty(cons(h,t)) folds to false and isEmpty(nil) to true (channel 1), and if not(isEmpty(l)) then head(l) discharges via channel 2 — so head types pure exactly where expected. On the abstract/lazy Stream, isEmpty is itself an EFFECTFUL observation (carries effect E, like splitFirst) with no static value, so the guard NEVER discharges and the Error would stick everywhere (worse than Option) — Stream must keep the Option/headOption form. So: Stream keeps headOption (rename/keep its current Option head); add a guarded head ONLY on concrete List (plus headOption on List for the branch-on-presence case). The current stdlib head lives on Stream (stream.anthill:24, returns Option, derived from splitFirst) and there is NO List.head today. NEEDS: an EmptyList error payload (sort/effect); verify isEmpty discharges on a cons literal and via an if not(isEmpty) flow-fact. Acceptance: head(cons(...)) and head inside if not(isEmpty(l)) type PURE (no residual Error); head on a possibly-empty l keeps Error[EmptyList] (must handle); headOption returns Option[T]; cargo-test green. Concrete instance/demonstrator of WI-566 (048 Phase 4); builds on WI-067 (discharge) + WI-479 (migration precedent).
