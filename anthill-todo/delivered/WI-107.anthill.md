## Description

Built-in numeric induction principles (Int.induction, BigInt.induction). Not derivable from constructor structure — kernel-emitted for primitive sorts at KB-init time. Forms (proposal 025 lines 189-203): `rule Int.induction(?P, ?lo, ?hi) :- ?P(?lo), (forall(?n), gte(?n, ?lo), lt(?n, ?hi), ?P(?n) -: ?P(add(?n, 1)))` (bounded well-founded); `rule BigInt.induction(?P) :- ?P(0), (forall(?n), gt(?n, 0), ?P(sub(?n, 1)) -: ?P(?n))` (strong induction). Headline driver: lf1 reachability proof (∀k ≥ 0. d_min ≤ d_k ≤ d_max) instantiates Int.induction with ?P = λk. d_min ≤ distance_at_step(k) ≤ d_max. Deliverables: hand-emitted rules in stdlib/anthill/prelude/int.anthill (or kernel synthesis if predicate-var literals can't be written by hand). Acceptance: lf1 safety_gps.anthill can reference Int.induction and the proof obligation reduces to base + step subgoals dischargeable by Z3.
