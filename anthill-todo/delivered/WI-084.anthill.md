## Description

Term-level named constants in anthill. Currently the language has primitive literals and entities but no way to declare a named constant of a primitive type. Workarounds (entity-as-constant + side fact, unit-sort with coercion) are clunky. Proposed shape: 'const NAME: Type = literal_expr' at namespace or sort scope, identifier-resolvable everywhere a term is expected. Drives: webots binding sentinels (CHANNEL_BROADCAST = -1, infinity-as-velocity-mode), magic numbers in the safety proof's KinematicAssumptions / DistanceBounds. Should compose with the proposal-026 expression evaluator so constant expressions can be folded at load time.
