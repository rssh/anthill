## Description

Codegen/realization effect-discharge check (the CAPABILITY GATE). An operation's RESIDUAL required effect row must be a SUBSET of the active profile's supported-effect set (the keys of its effect_map). An effect with no realization on the target profile is UNREALIZABLE there and must fail LOUDLY at load/codegen (repo principle: loud error over silent skip), never silently dropped. NEW and distinct from two neighbours: (1) WI-089 defines HOW cpp effects MAP (the effect_map; its deferred increment (b) migrates the still-hardcoded {Modify->lvalue ref, Error->tl::expected} to queryable keyed facts) -- this WI is the REJECTION of effects a profile can't realize, not the mapping; (2) WI-329 is HANDLER discharge (handle_K removes handled label K from the row) -- that only NARROWS the residual row and is an INPUT to this check, not this check. v1 operates on declared op effects (handlers unimplemented, so residual = declared); once WI-329 lands the residual narrows by handled labels. REPRESENTATION (corrected): rust_std/scala_std carry effect_map NESTED in a single LanguageMapping fact (List[EffectMapping]). cpp has NO effect_map facts yet -- still hardcoded in Rust (WI-089 deferred increment (b)); only cpp's TYPE renames went FLAT keyed TypeMapping facts, and that was a query-mechanism pivot (cpp-gen reads an IMMUTABLE &KB via kb.query_view, can't member-walk a nested list), NOT a rejection of LanguageMapping. So cpp's effect_map can simply live in a cpp LanguageMapping.effect_map like the others (then NO wrinkle), or go flat to match cpp's type renames -- that nested-vs-flat choice is WI-089's still-OPEN fork. Either way this check must read support through ONE uniform accessor the chosen representation projects to (a fully-qualified anthill.realization.realizes_effect(profile, effect, receiver) sibling to lower_type), never assuming a representation. Surfaces scala_std's 'async lands in cats_effect/zio' as a CHECKED error instead of silent absence; protects WI-570's cpp emitter from lowering ops whose effects the target can't realize; and is where the planned EMBEDDED cpp profile's small effect set (no Branch/Suspension under no-heap) is enforced. Acceptance: an op requiring an effect absent from the target profile's supported set fails codegen with a clear message naming the effect + profile; an op whose effects are all realized lowers fine; tested against at least one profile (rust_std now; cpp once WI-089(b) lands). cargo-test green.
