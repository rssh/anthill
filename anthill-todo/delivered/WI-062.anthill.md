## Description

Interpreter resource config (EvalConfig struct). Replace ad-hoc set_stack_depth_cap with a coherent config object: pub struct EvalConfig { depth_cap: Option<usize>, step_cap: Option<u64> }. depth_cap catches non-tail recursion; step_cap catches infinite tail loops (TCO means no stack growth, so depth_cap alone can't catch them). Add EvalError::StepsExhausted. Thread through Interpreter::with_config / config / config_mut. Default: depth_cap=Some(1_000_000), step_cap=None. Deprecate set_stack_depth_cap in favor of config mutation. Test: infinite tail recursion (loop() = loop()) with step_cap=1000 surfaces StepsExhausted cleanly. value_weight_cap (memory-weight tracking) is filed separately — add when embedding / untrusted input is a concrete use case.
