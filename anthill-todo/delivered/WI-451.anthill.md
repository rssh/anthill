## Description

Grammar+parse: NON-RIGID type-variable BINDERS for sort params (design path-dependent-types.md §5.4 'The carrier is a non-rigid type variable'). Accept three SYNONYMOUS spellings for a type-param variable -- 'sort X = ?' (existing), 'sort ?X' (the ?x logical-var marker prefix), 'sort [X]' (bracket binder, operation-style) -- PLUS the operation-style ENCLOSING LIST after the sort name: 'sort CpsMonad[F[T]]' (mirrors 'operation name[...]', grammar operation_type_param_list). The HIGHER-KINDED 'F[T]' (a param whose binder carries a bracketed member) is the one new param shape; simple params reuse the flat op-param shape. tree-sitter grammar.js corpus + parse/convert.rs IR. All spellings parse to the SAME IR as 'sort X = ?' for the no-member case; the marked structured form carries its member sub-decls. The marker DISTINGUISHES a param-variable from a concrete nested sort -- unmarked 'sort F {...}' parses UNCHANGED (still a concrete structured sort). Rust-only (grammar+parse).
