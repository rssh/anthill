## Description

Add an 'unclaim' command to the anthill-todo CLI. Today there is no way to release a claimed work item back to Open: the command set is init/add/status/list/next/show/claim/deliver/verify/feedback/delete/update/add-dependency/remove-dependency/graph/skill — 'update' explicitly PRESERVES status, and there is no unclaim/release/reopen. Releasing a claim currently requires hand-editing workitems.anthill (status: Claimed(agent,since) -> status: Open), which is error-prone. Add 'anthill-todo unclaim WI-NNN' that transitions a Claimed item back to Open (clearing agent/since). Consider: only valid from Claimed (error otherwise); honor --agent for symmetry/auditing; possibly a paired status-transition audit. ACCEPTANCE: 'anthill-todo unclaim WI-NNN' on a Claimed item sets it to Open; on a non-Claimed item it errors clearly; help lists it. SCOPE: anthill-todo CLI crate.
