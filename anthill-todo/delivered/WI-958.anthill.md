## description

Three spellings of 'operation -> its parent sort', all by qualified-name slicing.

MEASURED (WI-955 /simplify altitude pass, verified against the source):
  impl_parent_of_op        rustland/anthill-core/src/kb/typing.rs ~11890
  spec_op_parent_sort      typing.rs ~15162
  self_receiver_spec_sort  typing.rs ~20729

Each answers the same question - given an operation Symbol, which sort declares it - by stripping the LAST segment of the qualified name and calling try_resolve_symbol. Two of the three additionally gate on type_params_of_sort(parent).is_empty(). KnowledgeBase::declaring_scope_symbol (kb/mod.rs) answers it from the symbol table, and op_declared_type_param_var (typing.rs ~13513) already uses it with a doc that makes exactly this argument ('a qualified-name split would have to decide where the owner's name ends - <ns>.<Sort>.<op>.<T> has TWO plausible owners').

NOT A BUG, and do not open it as one: all three are correct BY CONSTRUCTION today, because their subject is a DIRECT child of the scope they want. WI-955's failure needed a depth-2 subject read by a depth-1 rule, which is not this shape. This is a one-owner cleanup - the value is that three copies of one query cannot drift, not that any is currently wrong.

DECIDE, do not assume: check each site's gate BEFORE merging. The two type_params_of_sort gates may be doing more than 'the owner is an operation' (compare WI-956 item 4, which flags the sibling kind_of-vs-has_kind divergence at ground_rigid_projection_if_concrete for the same reason).

ALSO in the neighbourhood, the INVERSE round-trip: sort_type_params_as_pairs (typing.rs ~26453) and type_param_vid_in_sort (~26474) rebuild '<parent_qn>.<param>' with format! + try_resolve_symbol. WI-954 flags this as 'the identity round-trips THROUGH STRINGS in both directions'; if WI-954 lands first, these go with it.

ACCEPTANCE: one owner, or a stated per-site reason why it must stay separate - written at the site, not just in this ticket. cargo-test green; say which tests fail when the merge is backed out.

SOURCE: WI-955 /simplify altitude review.
