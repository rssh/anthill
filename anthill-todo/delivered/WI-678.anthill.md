In execute.rs, coerce_to_single_goal_value (WI-513) collapses a goal list for a not/or wrapper: the single-goal case passes the Value through carrier-neutrally, but the multi-goal case reifies every goal Value to a TermId (goal_value_to_term -> occurrence_to_term), then synthesize_conjunction_rule mints _synth_N(?free_vars) :- body and converts the body TermIds STRAIGHT BACK to occurrences via term_body_to_nodes for assert_rule_debruijn_with_nodes. The goals START as Values (Node ones already occurrences) and END as occurrences (the sole stored rule-body form, WI-246) -- the TermId is a transient detour, NOT exploited for hash-consing (the WI-169 dedup memo keys on a storage-neutral Vec<SynthKey> structural fingerprint, deliberately never TermId identity). The assertion substrate is ALREADY carrier-agnostic: assert_rule_debruijn_with_nodes takes head: impl Into<Value> (WI-373, accepts a Value::Node/Entity head) + an occurrence body, and collects free vars natively (collect_value_head_vars + collect_occurrence_global_vars_ordered). FIX = drop the reify: (1) free-var frame -> replace collect_vars(TermId) with the existing occurrence-native collect_occurrence_global_vars_ordered over the goal occurrences; (2) head -> build _synth_N(?vars) as a Value (Entity/Node), not Term::Fn (assert already accepts impl Into<Value>); (3) THE ACTUAL WORK -> a TermView-native variant of append_synth_key (execute.rs:414): today it walks self.terms.get(TermId); since NodeOccurrence IS a TermView (head symbol / pos+named children / var leaves), the SAME SynthKey stream can be built from the view. Then occurrence_to_term (goal_value_to_term) AND term_body_to_nodes drop out of this path. CONSTRAINT: WI-169 relies on a WALK-PARITY invariant -- collect_vars and append_synth_key must visit vars in the same first-occurrence order so the De Bruijn-positional SynthKey keys line up (debug_asserted); the occurrence-native walks MUST preserve that order and the memo key MUST stay byte-identical so dedup is unchanged. SCOPE: only the multi-goal branch of coerce_to_single_goal_value / synthesize_conjunction_rule. LOW-VALUE/narrow (reify is cold -- bounded by the WI-169 memo to once per DISTINCT multi-goal body), but a genuine, sound term-only holdout in the WI-661 carrier-agnostic family. Acceptance: full cargo-test green + /code-review; behaviour identical (esp. WI-169 memo still dedups a repeated multi-goal not/or body to one _synth_N).
