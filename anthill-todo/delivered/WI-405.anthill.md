## Description

Typer GAP: the subtype relation (types_compatible) applies its helpers NON-UNIFORMLY across dispatch arms, causing latent FALSE-REJECTS. Surfaced by the WI-381 and WI-384 /code-reviews; both latent today (suite green) but real. FACET A (provider-admissibility, WI-384 deferred): sort_provides_admissibly (WI-344) is confined to the (sort_ref,sort_ref) bare<->bare arm of types_compatible_term_dispatch (anthill-core/src/kb/typing.rs ~9602); the (parameterized,sort_ref)/(sort_ref,parameterized) arms do sort_sym_compatible (nominal base) ONLY. So a value whose type is a PARTIAL parameterized form (e.g. a constructor result S[T=?_] after WI-384, or any S[bindings]) compared against a BARE provider spec Spec (where 'S provides Spec') loses provider admissibility -> false-reject. Not triggered: the only stdlib provider (List) is single-param so never produces a partial ?_; reproduces with a multi-param S[A,B] + fact Spec[carrier=S] + a constructor binding only A, returned where bare Spec is expected. FACET B (alias-resolution, WI-381 deferred): WI-381 wired resolve_alias_shape into the (sort_ref,parameterized)/(parameterized,sort_ref) arms (both carriers) but NOT the (sort_ref,sort_ref) arm; so two aliases of the same shape (sort IntList = List[T=Int]; sort IntList2 = List[T=Int]) compared bare<->bare do a nominal NAME compare only -> IntList does not conform to IntList2 (false-reject). ROOT CAUSE: relation helpers (alias-shape resolution, provider admissibility) are applied per-arm, not uniformly. FIX DIRECTION (pick one): (i) normalize/resolve at a SINGLE point before dispatch -- the WI-381 altitude option, but no single walk point covers types_compatible's TERM path (it does not walk at entry) and the blast radius is broad; or (ii) thread the helpers through the remaining arms ((sort_ref,sort_ref) alias resolution; provider admissibility in the parameterized<->sort_ref arms). ACCEPTANCE: a partial parameterized result conforms to a bare provider spec it provides; an alias conforms to a same-shape alias; regression tests for both facets; full anthill-core green. Rust-only (typer).
