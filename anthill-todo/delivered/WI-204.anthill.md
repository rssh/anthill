## Description

Bundle commands ported to FileBasedWorkitemStore (proposal 036 phase 3). Builds on WI-203 (spec + impl in place). Mechanical refactor of 'rustland/anthill-todo/anthill/main.anthill': each cmd_X body rewrites to use the WorkItemStore spec operations (next_id / lookup / commit / by_status_of / forget) instead of hand-built indexes and rebuild-per-command glue. Concretely retired: build_row_map, build_dep_map_acc, register_dependents, feedback_set, collect_feedback_set, max_id_in, id_suffix_of, parse_wi_suffix, parse_int_or_zero, parse_int_acc, digit_value, pad3, status_for_m, direct_dependents_m, append_string — ~120 lines of helper code that exists today only because each command rebuilds the indexes on every invocation. Replaced with: (a) cmd_status / cmd_show / cmd_list / cmd_graph / cmd_next call lookup + by_status_of for queries; (b) cmd_add fires next_id then commit; (c) cmd_claim / cmd_deliver / cmd_verify / cmd_update do lookup + commit (the spec's commit handles the persist / flush dance internally); (d) cmd_delete / cmd_remove_dependency call forget; (e) cmd_feedback / cmd_add_dependency add a Feedback fact via commit. Threading: bundle commands take 's: Cell[WIS]' (concrete, since the impl sort binds State = WIS); commit mutates via Modify[s]; subsequent reads on s see the updated state. No Pair[Int, S] return; Int return for exit code. Retrieve results are Term values until WI-189 lands — phase 3 still uses term_field / term_as_string for individual WorkItem field reads inside cmd_X bodies (Strategy A from proposal 036). Acceptance: cargo test green (existing cmd_X integration tests still pass — claim_test, status_test, delete_test, etc.); the ~120 lines of helper glue retire from main.anthill; live anthill-todo --anthill list / graph / show perf parity or better with today (queries route through QueryableStore.retrieve, which scans the same in-memory IFS cache that WI-187 already maintains). Independent of WI-189 — phase 3 lands the structural refactor with Term-typed results; WI-189 is a typed-surface follow-up.
