3. WHAT IT SAYS ABOUT S2–S4
---------------------------

(a) No library code moves. S2–S4 rewrite test rows only, and the implementation.

(b) S2's refusal (L1–L3) moves 40 rows, but only 5 are §9's own case. 4 are fixed by a
    bracket the reading must take in (above). The rest are four kinds of open slot §9 does not
    yet name: an effect row (11), an open fact (6), a slot left open by inference or by a partly
    open argument (8), a named requirement slot (2). Each is a question before S2 is built

(c) S2 changes nothing at run time by itself. A rule's parameter rigid in the body and fixed at
    the citation is a LOAD fact; at run time the clause reads `A` off the value in ~280 rows,
    because nothing carries the citation's `A` to it except a dictionary. So the citation's
    type reaching the clause is S3's dictionary, and the reads are S4's to remove.

(d) S3's "the citation passes `SortDomain[T = T]`" has to be built at EVERY citation of a typed
    column, the concrete ones included: 70 rows have the type fixed and the dictionary not
    passed today (36 marked, 34 bare).

(e) S4 (L4) moves 32 rows, and 26 of its 72 sites are a sort's own parameters in the sort's own
    operations: refused as written, such a sort writes `requires SortDomain[T = T]`, or the
    instance's own domain is passed with it.
