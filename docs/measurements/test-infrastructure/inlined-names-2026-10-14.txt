== 3. what is read, and what is refused ==
# THE NAMES. A clause's variables are `var_0` … `var_<size-1>` (`frame_size`: its head, body, bounds and type
# parameters). A rule read inlined — the multi-argument form (`inline_rule_call`) and the one-argument form
# (`translate_called_rule`) — has every variable its head was not passed a value or a variable for bound, when its
# frame is opened, to a name past every name of the document (`name_own_variables`, `next_own_variable`), in the
# order its head and body first name them; the worlds of one document run on (`read_worlds`). Its sorts are kept
# by those names (`keep_own_variable_sorts`) and join the clause's before the free variables are declared. In an
# inlined frame a variable nothing binds is an error now (`translate_expr`, "has no name in the document"); in the
# clause's own frame it goes by its index, as it did, and closes to that name (`close_occ`).
# THE HELPER. `bind_variable` at every site: a variable DEFINED is equated with the value (a numeral that is it says
# nothing); an ALIAS (bound to another variable's name since its frame was opened, `InlinedFrame::names`) gives
# the value to that variable; a variable WRITTEN — in an assertion, in what the frame binds another variable to, in
# a construction it holds (`any_fragment`) — is equated and stays a constant; otherwise substituted, as always. The
# hand-back asks it in the CALLER's frame, and only where the value differs from what was passed.
# CONSTRUCTIONS. A construction passed to an inlined rule's head is closed over the caller's frame (`bind_head_arg`);
# a closed field met by a head's variable is what the caller passed there. A variable bound to a construction
# written as a term is refused (`translate_expr`), in the clause's own frame and in an inlined rule's (§6 (5)).
#
