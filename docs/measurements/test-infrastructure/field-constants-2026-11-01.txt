== 2. the decisions ==
# NAMING (user, 2026-10-14; docs/smtlib-forward-mapping.md §7.6): a field read as a constant is the entity's
# qualified name with the field, written by `smt_symbol`; `sanitize_smt_id` goes.
# THE LIFT (user, 2026-11-01, option (b) of the two put to them): a lift reads the fact's value in place of the
# premise's variable — substituted where nothing wrote the variable yet, equated where something did — and names
# no constant. Option (a) was to carry the constant and its value with the lift's declarations.
# AN ENTITY OF NO FACT (user, 2026-11-01, as proposed): refused where a premise reads a field of it — in a
# proof's body, a world, a lift, an obligation — with the text "has no fact, and a premise here reads its fields
# off one: a field no fact gives has no value".
