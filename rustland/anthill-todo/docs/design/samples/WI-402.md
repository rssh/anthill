## description

Typer: ADMIT an abstract return WITH an ensures manifest -- translucent returns, the requires/ensures OUTPUT dual (docs/design/path-dependent-types.md sec.5). ensures result.K = String (= ML with type t = string, a manifest type spec as a postcondition; sound because types are terms so an equation is a fact) makes result.K manifest at the caller -> it grounds, roots at nothing local -> no escape, result usable. Generalizes the strict no-sealing rule: an abstract return member is admitted exactly when an ensures (or a type-arg, for the simple case -> DataProvider[K=String]) roots it back at the interface; the ensures must be COMPLETE (cover every otherwise-local-rooted member; a partial ensures still escapes -> rejected, no-silent-drop applied to returns). requires evidences abstract INPUTS, ensures evidences abstract OUTPUTS -- both discharged STATICALLY at the call site (dictionary-passing / req_insertion / 011 per-call elaboration).
